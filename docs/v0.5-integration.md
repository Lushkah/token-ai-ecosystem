# Lushka v0.5 integration

Integrated the supplied DEX Screener OpenAPI definition into a live market adapter.

Implemented:
- `/latest/dex/search?q=...` pair search
- `/token-pairs/v1/{chainId}/{tokenAddress}` token-pool lookup
- Mobile DEX Scanner screen
- Price, 24h volume, liquidity, chain and DEX display

The supplied Intel Arc installer remains under `mining/intel-arc/` for authorized
worker infrastructure. The mobile wallet does not silently mine.

The unrelated funding configuration remains excluded.
