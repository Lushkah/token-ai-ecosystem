# Security Policy

## Reporting Security Vulnerabilities

**Do not** open public issues for security vulnerabilities. Instead, please email security@tokenai.io with:

1. Description of the vulnerability
2. Steps to reproduce
3. Potential impact
4. Suggested fix (if available)

## Security Review Process

1. **Report Received**: Acknowledged within 24 hours
2. **Investigation**: Team investigates and verifies
3. **Fix Development**: Security patch developed
4. **Testing**: Comprehensive testing
5. **Release**: Security update released
6. **Disclosure**: Responsible disclosure

## Security Best Practices

### For Users
- Use strong passwords
- Enable 2FA
- Keep software updated
- Use hardware wallets
- Verify contracts

### For Developers
- Code review all changes
- Use security scanners
- Test edge cases
- Document security assumptions
- Report vulnerabilities responsibly
